## Troubleshooting

### Report not received?

1. Check Actions tab for errors
2. Verify secrets are set correctly
3. Check Telegram bot token is active (send `/start` to your bot)

### Want different schedule?

Edit `.github/workflows/daily-market-report.yml`:

```yaml
schedule:
  - cron: '0 0 * * *'  # 08:00 WIB
  # Change to:
  - cron: '0 12 * * *' # 20:00 WIB
  - cron: '*/30 * * * *' # Every 30 minutes
```

### Add more data sources?

Edit `scripts/market_report.py` and add functions for:
- Commodities (gold, oil)
- Stock indices (S&P500, NASDAQ)
- Crypto fear & greed index
- Technical levels
